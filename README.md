# SEM15ACTUAL – API Gateway con Ocelot (Gimnasio)

Tres proyectos independientes; el cliente solo conoce el **gateway**.

| Proyecto | Puerto local | Qué es |
|---|---|---|
| `GatewayApi` | 5000 | Ocelot 25.x. Único punto de entrada; valida el JWT (esquema `Bearer`) antes de reenviar |
| `Gimnasio/Gimnasio.Api` | 5055 | Microservicio 1: API en capas con JWT de la S14 (lógica sin cambios) |
| `InstructoresApi` | 5056 | Microservicio 2: instructores, datos en memoria, valida JWT, todo exige token |

La única modificación a la S14: el proveedor de EF Core es configurable (`Database:Provider` = `SqlServer` por defecto o `Postgres`) y `launchSettings` fija el puerto 5055.

## Tabla de rutas (`GatewayApi/ocelot.json`)

| Upstream (cliente → gateway) | Método | Downstream (gateway → servicio) | Token |
|---|---|---|---|
| `/gateway/auth/{everything}` | POST | localhost:5055 `/api/auth/{everything}` | No |
| `/gateway/auth/{everything}` | GET (perfil) | localhost:5055 `/api/auth/{everything}` | Sí |
| `/gateway/planes{everything}` | GET | localhost:5055 `/api/planes{everything}` | No |
| `/gateway/planes{everything}` | POST, PUT, DELETE | localhost:5055 `/api/planes{everything}` | Sí |
| `/gateway/socios{everything}` | GET, POST, PUT, DELETE | localhost:5055 `/api/socios{everything}` | Sí |
| `/gateway/instructores{everything}` | GET | localhost:5056 `/api/instructores{everything}` | Sí |

El rol (`Gerente` para crear/editar/eliminar planes, eliminar socios) lo sigue exigiendo `Gimnasio.Api` (403). `/gateway/planes/{id}/socios` pasa por la ruta pública de GET y la API responde 401 sin token.

En la nube se usa `ocelot.Production.json` (hosts públicos, `https`, puerto 443, `BaseUrl` del gateway). El gateway lo elige solo cuando `ASPNETCORE_ENVIRONMENT=Production` (valor por defecto en el contenedor).

## Ejecutar en local

Secretos por variables de entorno (nunca en el repo). La clave debe ser **la misma** en los tres:

```powershell
$env:Jwt__Key = "una-clave-aleatoria-de-32-caracteres-o-mas"
$env:ConnectionStrings__GimnasioDB = "Server=.\SQLEXPRESS;Database=GimnasioDB;Trusted_Connection=True;TrustServerCertificate=True"
dotnet run --project Gimnasio/Gimnasio.Api --launch-profile http
dotnet run --project InstructoresApi --launch-profile http
dotnet run --project GatewayApi --launch-profile http
```

(cada uno en su terminal; `ejecutar-local.ps1` hace lo mismo si tu política de PowerShell lo permite). Base local: `Gimnasio/Base_de_datos/GimnasioDB_Scrip.sql`. Pruebas: `Gateway.http`.

## Despliegue en la nube (gratis)

### Elección y justificación

| Pieza | Opción | Por qué |
|---|---|---|
| Hosting ASP.NET Core | **Render** (Web Service, Docker, plan Free) | Soporta .NET vía Dockerfile, HTTPS incluido, despliegue desde GitHub y sin tarjeta. Se duerme tras ~15 min sin tráfico (primer request lento). Alternativas: Azure App Service F1 (pide tarjeta), Somee (hosting antiguo, con límites) |
| Base de datos | **Neon PostgreSQL** (plan Free) | Gratis, sin tarjeta, sin caducidad, SSL. Azure SQL free exige suscripción con tarjeta |

Como Neon es PostgreSQL: se agregó `Npgsql.EntityFrameworkCore.PostgreSQL` en `Gimnasio.Datos`, `Program.cs` elige `UseNpgsql` si `Database__Provider=Postgres`, y el script se adaptó a `Gimnasio/Base_de_datos/GimnasioDB_Postgres.sql` (identificadores entre comillas, `GENERATED BY DEFAULT AS IDENTITY`, `BOOLEAN`, `NUMERIC`, `CURRENT_DATE`, sin `CREATE DATABASE`). Entidades, repositorios y servicios no cambian.

### Pasos

1. **Neon**: crea proyecto → copia host, usuario y contraseña. Abre el SQL Editor y ejecuta `GimnasioDB_Postgres.sql`.
2. Sube **esta carpeta** (`SEM15ACTUAL`) a un repositorio de GitHub (`.gitignore` ya excluye binarios y archivos de secretos).
3. **Render** → New → Blueprint → elige el repo (usa `render.yaml`) o crea 3 Web Services Docker con `Dockerfile` en cada carpeta. Variables de entorno:
   - Gimnasio API: `Database__Provider=Postgres`, `ConnectionStrings__GimnasioDB=Host=<host-neon>;Database=neondb;Username=<user>;Password=<pass>;SSL Mode=Require;Trust Server Certificate=true`, `Jwt__Key=<clave>`
   - InstructoresApi: `Jwt__Key=<la misma clave>`
   - GatewayApi: `Jwt__Key=<la misma clave>`
4. Si los nombres de servicio en Render difieren de `gimnasio-api-s15`, `instructores-api-s15`, `gateway-api-s15`, edita los hosts y el `BaseUrl` en `GatewayApi/ocelot.Production.json` y vuelve a desplegar.
5. Prueba con `Gateway.http` cambiando `@gw` a la URL pública (el primer request puede tardar ~1 min).

## Pruebas locales ya verificadas

Gateway + InstructoresApi (sin BD): 401 directo al servicio 2 sin token; 401 por el gateway sin token y con token alterado; 404 en id inexistente y ruta fuera de `ocelot.json`; 502 cuando el servicio de destino está detenido.
